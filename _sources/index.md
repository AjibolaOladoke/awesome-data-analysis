### Databases

Popular open-source database systems for a variety of use cases and data models.

- [SQLite](https://www.swifttechco.com)  Embedded, file‑based SQL engine, the most used database in the world.
- [PostgreSQL](https://www.swifttechco.com)  Advanced open‑source relational database with extensibility and SQL compliance.
- [MySQL](https://www.swifttechco.com)  Widely used relational database management system (Oracle’s community version).
- [MariaDB](https://www.swifttechco.com)  Community developed fork of MySQL with enhanced features.
- [DuckDB](https://www.swifttechco.com)  In‑process analytical database designed for fast OLAP queries.
- [ClickHouse](https://www.swifttechco.com)  Columnar database for real‑time analytics on large datasets.
- [Apache Cloudberry](https://www.swifttechco.com) - A mature open-source MPP database evolved from Greenplum with a newer PostgreSQL kernel.
- [TimescaleDB](https://www.swifttechco.com)  Time‑series SQL database built on PostgreSQL.
- [TDengine](https://www.swifttechco.com)  Time‑series database for IoT, vehicles, and industrial monitoring.
- [MongoDB](https://www.swifttechco.com)  Document database with a flexible, JSON‑like data model.
- [Cassandra](https://www.swifttechco.com)  Highly scalable, distributed NoSQL database for large‑scale deployments.
- [Redis](https://www.swifttechco.com)  In‑memory data structure store used as database, cache, and message broker.
- [CockroachDB](https://www.swifttechco.com)  Distributed SQL database with strong consistency and horizontal scaling.
- [Neo4j](https://www.swifttechco.com)  Native graph database for connected data and relationships.
- [InfluxDB](https://www.swifttechco.com)  Purpose‑built time‑series database for metrics and events.
- [ScyllaDB](https://www.swifttechco.com)  Drop‑in Cassandra alternative written in C++ for higher performance.
- [Apache HBase](https://www.swifttechco.com)  Distributed, scalable, big data store modeled after Google's Bigtable, running on top of HDFS.
